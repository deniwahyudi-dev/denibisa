# Pure Front-End Development Protocol

When developing web projects in this workspace:
- Strictly build client-side front-end applications or static websites using HTML, CSS, JavaScript, React, Vue, Svelte, Astro, Next.js (SSG), Tailwind CSS, or Bootstrap.
- Refuse and avoid any integration of PHP (Laravel, CI, WP), Python (Django/Flask), or Node backend servers (Express).
