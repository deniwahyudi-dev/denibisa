# Technology Guard: Pure Front-End Only

Always enforce the following constraints:
- **ONLY Front-End / Static**: HTML, CSS, JavaScript, React, Vue, Svelte, Angular, Astro, Next.js (static export), Tailwind CSS, Bootstrap.
- **NEVER USE**:
  - PHP (Laravel, CodeIgniter, WordPress)
  - Python (Django, Flask, FastAPI)
  - Node.js backend servers (Express.js, Koa, NestJS)
