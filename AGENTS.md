# Project Rules & Technology Constraints

## Allowed Technologies (Front-End & Static Only)
- HTML, CSS, JavaScript (ES6+)
- Front-End Frameworks / Libraries: React.js, Vue.js, Svelte, Angular
- Static Site Generators (SSG) / Meta-Frameworks: Astro, Next.js (Static Export), Nuxt, Hugo, Gatsby
- CSS Frameworks: Tailwind CSS, Bootstrap, Vanilla CSS

## STRICTLY FORBIDDEN Technologies
Under NO circumstances should the following technologies, dependencies, or back-end servers be used:
1. **PHP**: No PHP, Laravel, CodeIgniter, WordPress, or PHP runtime.
2. **Python Backend**: No Python, Django, Flask, FastAPI, etc.
3. **Node.js Server Backend**: No Express.js, NestJS, Koa, Fastify, or custom Node backend servers.
4. **Server Databases**: No MySQL, PostgreSQL, MongoDB, or server-side DB connections required to view the site.

All code must run entirely as a client-side web application or static site.
